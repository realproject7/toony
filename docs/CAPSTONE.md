# Quality evidence boundaries

Historical capstone reports and visual review records are retained locally.
They are not the acceptance record for the current product direction.

The synthetic scale fixture demonstrates mechanical execution of validation,
planning, image import, lint, measurement and export. It does not demonstrate
artwork quality, story quality, editor usability or professional episode output.
See [SCALE_FIXTURE.md](./SCALE_FIXTURE.md) for its technical scope.

Historical reference measurements counted panel bands, not necessarily literal
panels. Their observed ranges must not become a fixed episode-length target.

Current quality acceptance requires artwork the connected agent drew and
changed, lettering, consistent preview and export, and an explicit operator
verdict. Passing schema checks or
matching a measured craft band cannot substitute for that verdict.

The local planning folder records the current benchmark, limitations, failures
and next acceptance milestone. Locate it as described in
[PO_WORKFLOW.md](./PO_WORKFLOW.md).
